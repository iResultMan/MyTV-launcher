# Fonts

`onest-latin.woff2` and `onest-cyrillic.woff2` are the Latin and Cyrillic subsets of Onest (variable weight 300 to 400), served from this site instead of
Google Fonts so a visit sends nothing to a third party. Onest is licensed under the SIL Open Font License 1.1
(https://openfontlicense.org), copyright the Onest Project Authors.
