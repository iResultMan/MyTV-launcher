# Конфиденциальность

В лончере нет учётных записей, аналитики, рекламных идентификаторов и отправки отчётов об ошибках. Что он делает, всё на вашем ТВ, если не сказано иное:

| Что | Куда уходят данные |
|---|---|
| Служба специальных возможностей («Кнопка Домой») видит название приложения, которое вышло на экран, и, пока ТВ заблокирован, нажатия кнопок пульта. Содержимое экрана, текст и пароли она не читает. | Остаётся на ТВ. |
| Детский режим: расписание, PIN (хранится как хэш PBKDF2 с солью), подключённые телефоны (хэши токенов), журнал и таблица экранного времени за 30 дней. | Остаётся на ТВ. Стирается строкой «Стереть данные детского режима» (Проверка и настройка) или удалением приложения. |
| Управление с телефона по Wi-Fi: ТВ отдаёт страницу на порту 8787 телефонам домашней сети, подключённым по коду с экрана ТВ. Токен передаётся в заголовке, не в адресе; другие сети отклоняются. | Между ТВ и вашим телефоном в вашем Wi-Fi. |
| Служба семейных сообщений (необязательный `message_url` в теме) и ретранслятор погоды (необязательный `weather_url`) | Обычный http только на частные адреса домашней сети; всё остальное только по https. |
| Погода (только если тема задаёт координаты) | Координаты и IP-адрес уходят на api.open-meteo.com. Уберите координаты из темы, чтобы выключить. |
| «Смотреть далее» (по умолчанию выключено): читает карточки, которые приложения публикуют на ТВ, после вашего разрешения. Постеры загружаются по адресам, которые публикуют эти приложения. | Серверы постеров видят IP-адрес ТВ. Картинки кэшируются на ТВ (не больше 20 МБ). |
| Список языков (Настройки лончера > Язык) читает один публичный файл `languages.json` с raw.githubusercontent.com, когда вы открываете диалог; чтобы этого не было, задайте в теме пустой `languages_url`. | Обычный HTTPS-запрос к GitHub, который видит IP-адрес ТВ; никаких идентификаторов не передаётся. |
| О программе > Поддержать проект показывает QR-коды, которые ведут на Ko-fi и CloudTips (ссылки в `res/values/support.xml`, тема может их заменить или оставить пустыми). | Ничего: лончер только рисует коды и сам к этим сервисам не обращается; обращается телефон, который код прочитал. |
| Телефон и облако (Настройки лончера), **по умолчанию выключено**: когда родитель включает, ТВ регистрируется на облачном сервере и общается с ним по HTTPS. | Сервер узнаёт название ТВ, названия пакетов и подписи приложений на экране и когда экран был включён, последние события журнала и отправленные сообщения; не узнаёт код родителей, имя Wi-Fi и то, что смотрят. Данные старше 30 дней удаляются, а выключение удаляет данные ТВ на сервере. См. [cloud-protocol.md](cloud-protocol.md). |
| Ключи лицензии проверяются на ТВ без сети. | Ничего не отправляется. |
| Облачная связка (режим C) — черновик, в лончере её нет. | — |

Удаление данных: строка «Стереть данные детского режима», очистка данных приложения в настройках Android или удаление приложения.
